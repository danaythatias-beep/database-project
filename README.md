**Project Overview**
This repository contains SQL scripts used to build a comprehensive Monitoring Dashboard in Databricks SQL.
The dashboard provides insights into loan performance, disbursement trends, and credit quality metrics for financial portfolio analysis.

**Objectives**
- Track total loans, disbursed amounts, and outstanding balances
- Monitor Portfolio at Risk (PAR) and Non-Performing Loans (NPL)
- Analyze loan distribution by Days Past Due (DPD)
- Evaluate loan quality using OJK rating categories
- Visualize monthly disbursement and loan cycle performance

**Toolkit**
- Databricks SQL
- Delta Tables
- Loan Portfolio Dataset (Parquet/Delta format)
- Databricks Dashboard Visualization
